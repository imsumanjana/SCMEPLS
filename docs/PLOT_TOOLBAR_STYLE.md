# Plot typography toolbar

Every Matplotlib canvas in SC-MEPLS Analysis Studio has a **Plot typography** button in the same toolbar that contains Home, Back, Forward, Pan, Zoom, Subplot Configuration, and Save. The button is labelled with an `Aa` icon and is placed before the Save icon.

Use it to set:

- font family,
- axis/plot label size,
- tick label size,
- legend size,
- annotation/value-label size,
- title size,
- bold axis labels,
- bold tick labels,
- bold legends,
- bold annotations,
- bold titles.

The dialog can apply the setting to the current figure or all currently open figures. Exported high-resolution PNG files keep the same style visible in the GUI.
