# Plot Typography Controls

Each analysis tab includes a **Plot typography** section. These controls update the currently displayed Matplotlib figure before export.

Available settings:

- Font family, with editable font name field.
- Axis/plot label font size.
- Tick-label font size.
- Legend font size.
- Annotation and data-label font size.
- Title font size.
- Bold axis labels, tick labels, legends, annotations, and titles.

After changing the values, press **Apply Plot Style**. The tab redraws the figure using the selected settings. Exported PNG files use the same style visible in the GUI.

Recommended article setting:

- Font family: Times New Roman, Liberation Serif, or DejaVu Serif.
- Axis labels: 12--14 pt, bold.
- Tick labels: 10--12 pt.
- Legend: 10--12 pt.
- Export DPI: 600 or higher.
